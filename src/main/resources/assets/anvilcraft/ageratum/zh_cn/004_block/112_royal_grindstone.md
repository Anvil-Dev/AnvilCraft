# 皇家砂轮

<recipe id="anvilcraft:smithing/royal_grindstone"/>

去除工具上的**诅咒附魔**和因为使用铁砧而积累的**惩罚**

# 使用方法

1. 放入要净化的工具
2. 放入<ref item="minecraft:gold_ingot"/>或<ref item="minecraft:gold_block"/>
3. 拿取工具，消耗<ref item="minecraft:gold_ingot"/>和<ref item="minecraft:gold_block"/>
4. 拿取<ref item="anvilcraft:cursed_gold_ingot"/>

<info>
清除诅咒附魔需要一次消耗 16 个<ref item="minecraft:gold_ingot"/>，且无法使用<ref item="minecraft:gold_block"/>
</info>
