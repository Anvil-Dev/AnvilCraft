# 板条箱

<recipe id="anvilcraft:crate"/>

# 功能

- 可以容纳32组物品
- 不满一组的物品可以混合占用同一组空间，类似收纳袋

# 搜索

- 在搜索框搜索时，会检索<ref item="anvilcraft:crate"/>3x3x3以内的所有<ref item="anvilcraft:crate"/>

# 分类显示

1. 可以左击标绿若干分类，只显示同时满足所有标绿条件的物品
2. 可以额外增加分类标准，可以使用<ref item="anvilcraft:filter"/>自定义类别

# 合成窗口

1. 在仓库中放入<ref item="minecraft:crafting_table"/>和<ref item="minecraft:stonecutter"/>可以启用自带的合成窗口
2. 按住shift合成1组，按住空格合成8组（别忘了启用自动填充）
