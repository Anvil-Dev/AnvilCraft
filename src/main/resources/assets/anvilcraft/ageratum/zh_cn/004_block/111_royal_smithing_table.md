# 皇家锻造台

<recipe id="anvilcraft:smithing/royal_smithing_table"/>

# 功能

- 不消耗任何锻造模板的高级锻造台
- 可以调用相邻容器内的锻造模板
- 在GUI内，可以右击左侧列表内的模板，设置个人收藏模板并将其置顶

<info>
这该是第一个用皇家钢升级的物品，因为有了它之后，锻造就无需再消耗任何锻造模板
</info>
