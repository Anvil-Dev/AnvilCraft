# 加工台

<recipe id="anvilcraft:stamping_platform"/>

- 可以存储输入材料，但不存储输出产物
- 手持物品右击加工台上表面可以直接放入
- 可以直接吸收上方的物品掉落物
- 让<ref item="minecraft:anvil"/>从上方落下，即可[加工](../007_struct/000_anvil_processing.md)放在台面上的物品

# 改装

对<ref item="anvilcraft:stamping_platform"/>或任一加工台的侧面使用下列物品，可切换为对应的加工台：

- <ref item="minecraft:grindstone"/>：<ref item="anvilcraft:crushing_table"/>
- <ref item="minecraft:scaffolding"/>：<ref item="anvilcraft:sifting_table"/>
- <ref item="minecraft:iron_trapdoor"/>：<ref item="anvilcraft:unpacking_table"/>

切换加工台会消耗手中的改装材料，并返还原有改装材料。手持<ref item="anvilcraft:anvil_hammer"/>右键任意加工台的侧面，可将其还原为<ref item="anvilcraft:stamping_platform"/>并返还改装材料。
