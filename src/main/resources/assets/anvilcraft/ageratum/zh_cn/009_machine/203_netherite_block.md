# 加工：下界合金

这台机器实现了[量产下界合金](../008_recipe/210_netherite_ingot.md)

## <ref item="minecraft:netherite_block"/>机

<structure id="../../structures/machine/netherite_block.nbt"/>

使用前先在两侧板条箱填充足量的<ref item="minecraft:gold_block"/>和<ref item="minecraft:ancient_debris"/>

## 进阶版

<structure id="../../structures/machine/netherite_block_advanced.nbt"/>

这台下界合金机每秒能加工出 5个 下界合金块，效率极高，很适合存货一段时间后大量产出一批下界合金块。开机前记得给加热器通电！

<tip>
你也可以尝试设计其它架构的下界合金块机
</tip>
