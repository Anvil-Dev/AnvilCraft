# 获得

- 通过[物质解压器](../004_block/402_mega_structure.md#物质解压器)生产

# 特性

- 只要与其他<ref item="anvilcraft:excited_state_void_matter_block"/>接触，就会衰变为这些产物之一：红石块、青金石块、钻石块、下界合金块、铀块、钚块、蓝宝石块、红宝石块、黄玉块
- 如果衰变时有相邻的<ref item="anvilcraft:confinement_chamber"/>，还会产生四种砧子
- 使接触到的<ref item="anvilcraft:void_matter_block"/>立刻衰变
