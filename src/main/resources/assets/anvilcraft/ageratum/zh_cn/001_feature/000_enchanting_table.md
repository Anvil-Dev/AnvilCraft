# <ref item="minecraft:enchanting_table"/>增强

在附魔台上附魔特定材料的物品，有更高概率获得对应附魔（其中一些附魔只能通过在附魔台上给对应材料的工具附魔取得）

| 物品                                            | 附魔                 |
|-----------------------------------------------|--------------------|
| [皇家钢工具](../002_material/110_royal_steel.md)   | 精准采集、耐久            |
| [浮霜金属工具](../002_material/202_frost_metal.md)  | 崩解（独有）             |
| [余烬金属工具](../002_material/211_ember_metal.md)  | 熔炼（独有）、火焰附加        |
| [超限合金工具](../002_material/312_transcendium.md) | 时运、抢夺（都有概率提升至4、5级） |
