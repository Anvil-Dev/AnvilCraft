# 铁砧抢夺

# 定义

当生物被坠落的铁砧击中时，会根据**生物受到的伤害占其最大生命值的比例**，触发额外的战利品掉落

| 伤害占比 | 额外掉落倍率 |
|:----:|:------:|
| ≥40% |   1    |
| ≥60% |   2    |
| ≥80% |   3    |

<info>
如果这次铁砧伤害直接击杀了生物，则除了正常的死亡掉落外，根据此次生物受到的伤害同样按上述规则追加对应倍率的额外掉落物。
</info>

<tip>
有一些生物(女巫、铁傀儡)可以自行或借助外力恢复血量，你可以借此制造不杀死生物的掉落物农场: [刷铁机](../009_machine/001_iron.md)
</tip>

# 高级铁砧额外效果

- 使用<ref item="anvilcraft:ember_anvil"/>可以产出本需要玩家**手动击杀**而产生的掉落物

<info>
例如烈焰人本需要由玩家击杀才掉落烈焰棒，想要自动处死获得掉落物就必须依赖<ref item="anvilcraft:ember_anvil"/>
</info>

- 使用<ref item="anvilcraft:transcendence_anvil"/>可以产出本需要玩家**手动击杀**而产生的掉落物。获得更多掉落。
