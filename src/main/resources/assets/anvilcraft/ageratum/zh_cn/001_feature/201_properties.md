# 属性

本页面展示了目前所有可用的特殊工具属性，以及它们的效果

# 重铸

- 来自[余烬金属工具](../002_material/211_ember_metal.md)
- 工具能在高温中恢复耐久

| 方块(流体) | 恢复的耐久/gt |
|--------|----------|
| 火      | 2        |
| 灵魂火    | 5        |
| 熔岩     | 10       |
| 熔岩炼药锅  | 10       |

# 无情

- 来自[浮霜金属工具](../002_material/202_frost_metal.md)
- 拥有 **无情** 的武器工具，所有附魔都会失效
- 将失效的附魔的等级，转换为攻击伤害和挖掘速度
  - 攻击伤害: 2*√n + n/3
  - 挖掘速度: n

# 多相

拥有此属性的工具通常从两个“相位”开始，底层数据支持 2 至 4 个相位。
每个相位会存储自己的名称、修复花费和附魔，彼此不会冲突。
短按 <key id="key.anvilcraft.switch_phase" /> 可以循环切换相位；按住超过 4 个客户端 tick 会打开相位轮盘，然后可以直接选择相位。

# 永恒

- 来自[超限合金工具](../002_material/312_transcendium.md)
- 工具不再消耗耐久，耐久时刻保持为满（同时加上原版不可破坏的属性，作为双保险）
- 工具免疫火焰、爆炸、仙人掌伤害，不会坠入虚空，在y小于Ymin+5的区域缓慢上浮
- 工具掉在地上不会随着时间消失

# 强运

- 来自[超限合金工具](../002_material/312_transcendium.md)
- 拥有 **强运** 属性的工具触发白名单内的附魔时，有25%概率再触发一次，有5%概率再触发两次（一次掉三个头、一次钓出三条鱼是可能的）
  - 目前支持的附魔: 时运、抢夺、斩首、荆棘、海之眷顾
