# 伐木

- 附魔等级上限：III
- 铁砧消耗系数
- 功能：伐木时，每级额外破坏 4 个相连的原木
- 获取方式：制作<ref item="anvilcraft:amethyst_axe"/>

# 收割

- 附魔等级上限：III
- 功能：右键点击成熟庄稼可范围收获并补种，也可破坏范围内的杂草和树叶；每级扩大一圈范围
- 获取方式：制作<ref item="anvilcraft:amethyst_hoe"/>

# 斩首

- 附魔等级上限：III
- 功能：每级提高生物掉落头颅的概率，对凋零骷髅提升更高，对玩家和末影龙提升极高
- 获取方式：制作<ref item="anvilcraft:amethyst_sword"/>

<info>
斩首III附魔的武器必定可以砍下<ref item="minecraft:dragon_head"/>
</info>

# 崩解

- 附魔等级上限：I
- 功能：破坏方块时，使得掉落的经验值提高 4 倍，再将每个掉落物转化为 1 点经验值
- 获取方式：通过[特殊方法](000_enchanting_table.md)获得

# 熔炼

- 附魔等级上限：V
- 功能：破坏方块时，将掉落物烧制一次
- 获取方式：通过[特殊方法](000_enchanting_table.md)获得
