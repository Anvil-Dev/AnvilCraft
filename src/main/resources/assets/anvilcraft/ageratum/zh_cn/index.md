# 介绍

## 欢迎来到《铁砧工艺》

铁砧工艺是一个从原版铁砧下落机制和铁砧锻造机制出发，通过与传统科技模组不同的思路扩展出完整科技体系，在最后甚至可以锻造行星、恒星和黑洞的模组。主要内容有：

- 方块处理：铁砧落在需要被加工的方块上加工该方块，下方不同的方块会有不同的效果
- 物品处理：铁砧落在方块上可以处理该方块上方或者内部的物品，不同的方块完成不同的处理
- 更多铁砧处理：铁砧砸到生物，红石块，刷怪笼等会引起相应变化
- 原版改进：为了让铁砧处理更加丝滑，本模组增加了原版本应该就有的功能
- 更多实用物品：帮助玩家更好的完成自动化或者获取资源
- 电力科技：简单易上手但功能强大的一系列设备
- 锻造增强：使用魔法材料来获得更加强力的武器工具。

# 手册使用导引

<tip>
一定要看我，让你的手册阅读体验上升
</tip>

1. 如果第一次游玩，**强烈建议**根据《主线流程》来阅读。但这并非硬性要求，你也可以根据自己的兴趣来阅读与游玩
2. 蓝色的[词条](000_process/001.md)是可以点击并跳转的超链接
3. 在 config/Ageratum 中可以调整手册的缩放（scale）程度，选择合适的字号大小
4. 手册右边的按钮可以添加书签，ctrl+右键可以删除书签
5. 书中的结构可以用鼠标旋转和移动，也可以通过右上角的按钮投影：

- 可以通过PgUP/PgDN按钮跳转只显示哪一层（一般位于小键盘的上下箭头，部分笔记本需要同时按下Fn）
- 可以通过END按钮取消投影
- 以上按钮均可以通过自定义按键调整
