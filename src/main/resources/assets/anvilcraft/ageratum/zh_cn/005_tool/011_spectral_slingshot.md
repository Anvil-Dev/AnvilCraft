# 使用

- 用法类似无需箭矢的<ref item="minecraft:crossbow"/>，且装填不消耗弹药
- 装填时另一只手需持有武器；射击造成该武器近战伤害的 50%（原武器只有增伤附魔生效）

# 附魔说明

- 快速装填：缩短装填时间，并降低射击冷却
- 无限：射击后保留已装填的幻影，无需再次装填；Shift+右键可清空已装填的幻影
- 力量：增加弹射物伤害（与原版箭矢不同，每级只增加 10% 伤害）
- 其余附魔和原版一致
