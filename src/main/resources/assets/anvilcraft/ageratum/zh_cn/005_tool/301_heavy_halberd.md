# 重戟

<row halign="center">
<item id="anvilcraft:heavy_halberd_core"/>
<item id="anvilcraft:ember_metal_heavy_halberd"/>
<item id="anvilcraft:frost_metal_heavy_halberd"/>
<item id="anvilcraft:transcendence_heavy_halberd"/>

- 万能武器，能作为四种近战武器使用，但所有模式的攻击都有重锤的下落高度加成
- 普通耐久损伤会保留最后一格耐久缓冲，因此重戟不会在正常使用中损坏。如果物品已经处于过度损坏阈值，工具组件和基础攻击属性会被移除，修复后恢复；在该状态下右键使用和三叉戟模式投掷都会被拒绝
- 按住[左alt]键呼出轮盘，轮盘上有四个选项，不同选项下拥有不同右键能力
  - <ref item="minecraft:trident"/>模式：右键投掷
  - 矛模式：右键戳刺(没有矛的MC低版本无功能)
  - 剑模式：右键格挡，减少受到的物理伤害
  - <ref item="minecraft:mace"/>模式：右键无功能，但攻速很快
