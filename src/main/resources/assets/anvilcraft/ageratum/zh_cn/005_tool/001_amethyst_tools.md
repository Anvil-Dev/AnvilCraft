## 紫水晶工具

- **便宜还好用的工具**
- 紫水晶工具自带附魔

| 工具 | 附魔（合成赋予的等级 / 等级上限） | 附魔功能                               |
|----|--------------------|------------------------------------|
| 镐  | 时运 III / III       | 增加矿物掉落（帮助获得更多铁矿）                   |
| 斧  | 伐木 I / III         | 伐木时，每级额外破坏 2 个相连的原木                |
| 锹  | 效率 III / V         | 提高破坏效率                             |
| 锄  | 收割 I / III         | 右键成熟庄稼可收获并补种，也可破坏范围内的杂草；每级额外收割一圈范围 |
| 剑  | 斩首 I / III         | 每级提高生物掉落头颅的概率，对玩家和末影龙概率极高          |
