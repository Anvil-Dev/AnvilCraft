# 共振器

<row halign="center">
<item id="anvilcraft:resonator_core"/>
<item id="anvilcraft:ember_metal_resonator"/>
<item id="anvilcraft:frost_metal_resonator"/>
<item id="anvilcraft:transcendence_resonator"/>
</row>

- 万能工具，可以挖任何方块
- 可损坏的共振器达到最后一格耐久缓冲后不会完全损坏，类似于<ref item="minecraft:elytra"/>。此时工具组件和基础攻击属性会被移除，且无法开始共振挖掘；修复到阈值以下后会恢复这些能力
- 按住[左alt]键呼出轮盘，轮盘上有五个选项
  - 默认选择Auto，加速破坏任意方块
  - 选择对应的工具类型时，只加速破坏对应的方块，但可以执行相应的*去皮*、*耕地*等操作
- 共振挖掘：对任意方块长按右键一小段时间立刻挖掘下来，专治坚硬方块 (<ref item="minecraft:bedrock"/>这类方块除外)，但需要消耗工具 128 点耐久
