# 铁砧锤

<recipe id="anvilcraft:anvil_hammer"/>

## 功能

- *铁砧锤*是本模组的扳手
  - 右键可以调整某些方块的方向，蹲下右键可以拆除某些方块
  - 左键方块对方块执行铁砧砸到方块的操作
- 右键长按，可以作为**对应的铁砧**来使用
- 可以**戴在头上**作为护目镜，查看电网信息
- 可以**戴在头上**作为头槌，鞘翅飞行撞击生物造成伤害
- 作为重锤，从高处落下攻击生物对生物追加如同铁砧下落增加的伤害
- 主手持有铁砧锤时，副手持<ref item="minecraft:firework_rocket"/>对脚下的方块使用，可以向上**火箭跳**，烟花等级越高跳的越高

<warning>
注意，左键敲击方块、左键攻击生物以及头槌撞击生物会消耗铁砧锤的耐久，其他操作不会
</warning>
