# Introduction

## Welcome to AnvilCraft

AnvilCraft starts from vanilla's falling-anvil and anvil-smithing mechanics and expands them through an approach different from traditional tech mods into a complete technological system. By the end, you can even forge planets, stars, and black holes. Its main features include:

- Block Processing: an anvil falling onto a block processes that block, with different blocks underneath producing different effects
- Item Processing: an anvil falling onto a block can process items above or inside that block, with different blocks providing different processing
- More Anvil Interactions: anvils striking mobs, redstone blocks, spawners, and more trigger corresponding changes
- Vanilla Improvements: to make anvil processing smoother, this mod adds features that should have existed in vanilla
- More Useful Items: help players better automate production or obtain resources
- Power Technology: a series of devices that are easy to learn but powerful
- Smithing Enhancements: use magical materials to obtain more powerful weapons and tools.

# Guide Book Usage

<tip>
Be sure to read this — it will greatly improve your reading experience
</tip>

1. If this is your first time playing, it is **strongly recommended** to follow the "Main Progression" chapter. But this is not a strict requirement — feel free to read and play according to your own interests
2. Blue [terms](000_process/001.md) are clickable hyperlinks that jump to related pages
3. You can adjust the scale of the guide book in `config/Ageratum` to choose a comfortable font size
4. The buttons on the right side of the book allow you to add bookmarks. Ctrl + right-click removes a bookmark
5. Structures in the book can be rotated and moved with the mouse, and projected via the buttons in the top-right corner:

- Use the PgUp/PgDN buttons to switch which layer is displayed (typically the up/down arrow keys on the numpad; on some laptops you may need to hold Fn)
- Press the END button to cancel the projection
- All of these buttons can be customized in the key bindings
