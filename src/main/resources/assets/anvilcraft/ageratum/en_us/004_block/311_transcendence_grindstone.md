# <ref item="anvilcraft:transcendence_grindstone"/>

<recipe id="anvilcraft:two_to_one_smithing/transcendence_grindstone"/>

## Function

- Has all the functions of <ref item="anvilcraft:royal_grindstone"/>, <ref item="anvilcraft:frost_grindstone"/>, and <ref item="anvilcraft:ember_grindstone"/>
- The function is determined by the **lower-left** slot

| Item | Function | Source |
| --- | --- | --- |
| <ref item="minecraft:gold_ingot"/> or <ref item="minecraft:gold_block"/> | Removes penalties or curse enchantments | <ref item="anvilcraft:royal_grindstone"/> |
| Empty | Removes enchantments and produces more experience orbs | <ref item="anvilcraft:frost_grindstone"/> |
| <ref item="minecraft:book"/> or other enchantable items | Transfers enchantments (multiple selection allowed) | <ref item="anvilcraft:ember_grindstone"/> |
| Empty <ref item="anvilcraft:fluid_tank"/> | Removes one enchantment and stores it in the tank as liquid enchantment | <ref item="anvilcraft:ember_grindstone"/> |
| Empty <ref item="anvilcraft:large_fluid_tank"/> | Removes multiple enchantments and stores them in the tank as liquid enchantment | <ref item="anvilcraft:ember_grindstone"/> |
