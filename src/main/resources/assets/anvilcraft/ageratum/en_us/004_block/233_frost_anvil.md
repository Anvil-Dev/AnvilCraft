# Frost Anvil

<recipe id="anvilcraft:smithing/frost_anvil"/>

## Forge Capabilities

- Has all the smithing capabilities of <ref item="anvilcraft:royal_anvil"/>
- When merging enchantments, the anvil penalty increases more slowly, +1 each time (vanilla is *2)
- Can consume *Frost Metal* to repair any tool without increasing anvil penalty
- Naming items costs no experience and does not increase anvil penalty

## Processing Capabilities

- When participating in [Anvil Mining](../001_feature/000_anvil_destroy.md), gains [Disintegration](../001_feature/100_enchantment.md#disintegration) effect
- When a Sculk Block is crushed on a cauldron by a <ref item="anvilcraft:frost_anvil"/>, there is a 40% chance to add one layer of [Experience Fluid](../002_material/004_exp_gem.md), four times the chance of a normal anvil
