# Royal Anvil

<recipe id="anvilcraft:smithing/royal_anvil"/>

## Forge Capabilities

- <ref item="anvilcraft:royal_anvil"/> never takes damage
- Will not trigger "Too Expensive" when smithing
- Using a <ref item="minecraft:name_tag"/> with special characters allows you to style item names

## Processing Capabilities

- When participating in [Anvil Mining](../001_feature/000_anvil_destroy.md), gains *Silk Touch* effect
- When participating in [Anvil Looting](../001_feature/000_anvil_loot.md), can deal up to 80 damage instead of the normal anvil's 40
