# Royal Grindstone

<recipe id="anvilcraft:smithing/royal_grindstone"/>

Removes the **curse enchantments** from a tool and the **penalties** accumulated from using an anvil

# How to Use

1. Place the tool to purify
2. Place a <ref item="minecraft:gold_ingot"/> or <ref item="minecraft:gold_block"/>
3. Take the tool, consuming <ref item="minecraft:gold_ingot"/> and <ref item="minecraft:gold_block"/>
4. Take out the <ref item="anvilcraft:cursed_gold_ingot"/>

<info>
Removing curse enchantments costs 16 <ref item="minecraft:gold_ingot"/> at once and a <ref item="minecraft:gold_block"/> cannot be used
</info>
