# Crate

<recipe id="anvilcraft:crate"/>

# Function

- Holds 32 stacks of items.
- Partial stacks can share the same stack space, similar to a bundle.

# Search

- When using the search box, all <ref item="anvilcraft:crate"/>s within a 3x3x3 area are searched.

# Classification Display

1. Left-click categories to mark them green. Only items that match every green condition are displayed.
2. Additional classification criteria can be added, and custom categories can be created using a <ref item="anvilcraft:filter"/>.

# Crafting Window

1. Place a <ref item="minecraft:crafting_table"/> and a <ref item="minecraft:stonecutter"/> in the storage to enable the built-in crafting window.
2. Hold Shift to craft one stack, or hold Space to craft eight stacks (remember to enable auto-fill).
