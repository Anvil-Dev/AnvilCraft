## 提交节点

## 放置器基础设施阶段（2026-09-13）

### 已迁移的规则与指针

- `block/placement/`、`BlockPlacementRules`、`IBlockPlacementRule` 及代码回退注册已迁入。
  规则注册表保持数据包覆盖优先级，支持状态表达式、继承/清除属性、跨方块转换、禁止放置、数量与返还物品。
- 26.1 在规则生成和加载时尚未绑定物品默认组件，直接构造 `ItemStack` 会实际报 `Components not bound yet`。
  `StateRule` 因此保存 `Optional<ItemStackTemplate>`，在运行时请求放置材料时才实例化物品栈；
  字符串、带数量/组件的对象、空对象表示禁止放置的 JSON 合同不变。
- `ModBlockPlacementRuleProvider` 已接入客户端/服务端数据生成。
  254 份规则中，245 份共有规则与源分支 JSON 完全一致；新增 9 份来自 26.1 的原版方块。
  源分支剩余 4 份（巨型石碑核心及 3 种玻璃管）需随对应方块迁移补齐。
- `IBlockItem`、`BlockPlacementUtil`、`BlockStateAndEntity` 已迁入，包含蓝图坐标/朝向与上下翻转、多方块部件枚举及状态应用。
- 三类目标指针及 5 个注册类型已接入：方块、容器物品、掉落物。
  容器指针使用 26.1 `ResourceHandler<ItemResource>` 与事务 API 模拟/执行消耗，不引入旧 `IItemHandler`。
  指针仍保存源版本的类型 ID、位置、方向、物品/状态与默认朝向等信息。
