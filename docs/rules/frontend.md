# 前端开发规范

本规范仅适用于 `web/` 目录下的前端项目。修改依赖、界面样式或交互组件前先阅读本文全文。

## 包管理与脚本

依赖安装与脚本运行必须使用 `pnpm`，禁止使用 `npm` 或 `yarn`，防止锁文件冲突。

## 颜色与主题

界面颜色优先使用 Arco Design 提供的 CSS 变量（如 `var(--color-bg-2)`、`var(--color-text-1)`、`rgb(var(--primary-6))`），使页面自动兼容深色与浅色主题切换。

确需自定义颜色时，必须同时实现深色与浅色两套样式：通过 `body[arco-theme='dark']` 选择器提供深色模式取值，禁止只写死一套颜色。该选择器直接写在 Vue `scoped` 样式中会失效，必须放在全局样式文件或配合 `:deep()` 使用。

## 滚动区域与弹出层

界面中所有滚动区域统一使用 Arco Design 滚动条组件并隐藏滚动条轨道，禁止使用浏览器原生滚动条。

界面中所有弹出层必须在顶部和底部与页面边缘之间留有空白，禁止撑满整个页面高度；内容超出高度时在弹出层内部滚动。
